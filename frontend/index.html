FastAPI Endpoints

Programmatic Multi-Agent API

Integrate the Azure Multi-Agent Business Assistant into your enterprise pipelines, Slack, or Teams.

POST /api/query

Executes full multi-agent orchestration (Orchestrator -> Research -> Analyst -> Strategy) and returns synthesized report.

curl -X POST http://localhost:8000/api/query \
  -H "Content-Type: application/json" \
  -d '{"query": "Analyze SaaS gross margin benchmarks", "document_ids": ["doc-01"]}'
GET /api/agents

Lists all 4 registered Azure AI Foundry agents with models, system prompts, and assigned tools.

curl http://localhost:8000/api/agents
